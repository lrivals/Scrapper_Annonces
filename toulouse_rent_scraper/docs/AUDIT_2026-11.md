## Synthèse

Le pipeline fonctionne de bout en bout (scraping SeLoger/LBC → filtre prix/distance → SQLite → enrichissement → UI liste/carte), mais :

1. **Des bugs faussent les résultats** : prix ≥ 1000 € mal parsés, annonces expirées jamais réactivées, annonces supprimées qui reviennent, géocodage biaisé hors Toulouse, URLs de recherche incohérentes avec la config.
2. **La dette technique freine les évolutions** : code Chrome/anti-bot dupliqué, `ui.py` monolithique (1330 lignes), migrations ad hoc, config morte.
3. **L'UI locale est exposée au CSRF** : une page web quelconque peut vider la base.
4. **La valeur métier plafonne** : pas d'alerte ni de planification (les bonnes annonces partent en quelques heures), pas de score pour prioriser.

## 🔴 Bugs (impact direct sur les résultats)

### B1 — `parse_price` faux pour les prix ≥ 1000 €
- **Où** : `filters/price_and_distance.py:27` — `re.search(r"(\d{2,4})", cleaned)`
- **Symptôme** : le premier groupe de 2–4 chiffres est pris.
  | Entrée | Résultat | Attendu |
  |---|---|---|
  | `"1 200 €"` | 200 | 1200 |
  | `"1 050 €"` | 50 | 1050 |
  | `"5 €"` | None | 5 (puis rejeté par MIN) |
- **Impact** : des loyers hors budget passent le filtre `MAX_RENT_EUR` avec un prix faux en base.
- **Correction** : [11.1](SPRINT_11.md#111--parse_price-robuste)

### B2 — Annonce expirée jamais réactivée
- **Où** : `storage/sqlite.py:103` (`insert_annonce`), ligne 124 : seul `scraped_at` est mis à jour.
- **Symptôme** : une annonce marquée `expired` par `--check-links` (faux positif réseau, republication) reste `expired` même si elle réapparaît dans les résultats de recherche.
- **Correction** : [11.2](SPRINT_11.md#112--réactivation-et-mise-à-jour-dans-insert_annonce)

### B3 — Suppression UI inopérante
- **Où** : `ui.py:1104` — `DELETE FROM annonces WHERE id = ?`
- **Symptôme** : l'annonce est réinsérée comme « ✨ Nouvelle » au scraping suivant. Impossible d'écarter durablement une annonce.
- **Correction** : [11.3](SPRINT_11.md#113--statut-hidden-au-lieu-du-delete)

### B4 — Géocodage biaisé et coûteux
- **Où** : `geo/distance.py:51` (suffixe `", Toulouse, France"` systématique), `geo/distance.py:37` (`init_db()` à chaque appel).
- **Symptômes** :
  - « Ramonville-Saint-Agne 31520, Toulouse, France » / « Muret 31600 Centre-ville, Toulouse » → échec ou mauvais point.
  - Les échecs ne sont pas mis en cache → Nominatim rappelé à chaque run (+1 s/adresse, risque 403).
  - `init_db()` rejoue toutes les migrations (PRAGMA + ALTER checks) pour chaque annonce.
- **Correction** : [11.4](SPRINT_11.md#114--géocodage-fiable)

### B5 — URLs de recherche incohérentes avec la config
- **Où** : `config.py:63-71` (SeLoger), `config.py:97-104` (LBC)
- **Symptômes** :
  - LBC `price=350-max` : ignore tout ce qui est < 350 € et ramène > 500 € (pages gaspillées, DataDome sollicité pour rien).
  - SeLoger `classifiedBusiness=Professional` + `estateSubTypes=Studio` : exclut particuliers, T1, T2.
  - `MIN_RENT_EUR` / `MAX_RENT_EUR` ne sont pas injectés dans les URLs.
- **Correction** : [11.5](SPRINT_11.md#115--urls-de-recherche-dérivées-de-la-config)

### B6 — Détection de doublons incohérente et non persistée
- **Où** : `storage/sqlite.py:173-216`
- **Symptôme** : docstring « même site, ±5 € » ≠ code « site différent, ±1 €, ≥ 2 mots communs ». Le résultat n'est que loggé : l'UI affiche les deux annonces.
- **Correction** : [11.6](SPRINT_11.md#116--doublons-cohérents-et-persistés)

## Ce qui est bien et à conserver

- Profil Chrome persistant + CDP : contournement DataDome qui marche ; le garder, juste le factoriser.
- `scroll_into_view_if_needed()` par carte (lazy-loading LBC) : à conserver dans le refactor de `_scrape_current_page`.
- Cache géocodage SQLite et `LEFT JOIN` carte : bonne base, à compléter par un cache négatif.
- `insert_annonce` retournant `new/updated/unchanged` : point d'accroche idéal pour les notifications.
- Pattern `allowed_fields` de `update_annonce_enrichment` : à réutiliser pour toute mise à jour dynamique.
- Imports lazy dans `main.py` : à préserver (l'UI doit démarrer sans Playwright).
